# Leadora

一个持续迭代的内容创作、发布与多账号运营工作台。

我希望把原本分散的内容准备、发布、设备与账号管理、消息处理集中到一个工作台里，减少来回切换，让操作者能看清当前状态和操作结果。

## 我负责什么

我主要负责产品需求、交互设计、功能优先级、真实使用反馈与验收，并使用 AI 编码工具协作实现。迭代从实际问题出发：把问题整理成需求，明确操作流程，再核对界面反馈和实际执行能否对应。

## 开发过程

- 拆解内容准备、发布与运营中的重复操作。
- 整理功能之间的共同需求，减少不同入口各自维护一套逻辑。
- 根据使用反馈调整交互、状态提示与设置反馈。
- 核对规则、执行结果与处理记录，并持续补齐稳定性问题。

## 技术栈

Python、JavaScript、SQLite、桌面客户端与 Android 设备接入。

项目仍在持续迭代，优先完善现有功能与稳定性。没有在这里发布未经核实的客户规模、商业收益或效率提升数字。
