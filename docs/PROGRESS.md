## 最近一批已接入的变化

| 变化 | 解决的问题 |
| --- | --- |
| 通用规则按实际修改字段覆盖 | 只改账号个别设置时，其余要求继续继承通用规则。 |
| 训练读取实际生效规则 | 减少训练试答与正式回复使用不同设置的问题。 |
| AI 业务资料保存、查看、更新与撤销 | 将用户明确提供的业务事实接到资料库，和通用回复要求分开。 |
| 评论优先级与等待时间用于队列 | 让已有判断进入排队处理，避免只在界面展示分数。 |
| 当前评论草稿与人工编辑保护 | 减少后台任务干扰正在处理的评论。 |
| 浏览器账号历史处理记录分页和定位 | 查询当前可访问账号的记录，减少遗漏早期内容或跳到错误消息的问题。 |

## 已有验证记录说明了什么

最近交付有相关隔离回归、正式环境加载和实际网页只读检查记录。核实范围包括：

- 通用规则继承、账号例外和训练规则范围。
- 业务资料版本与撤销，以及当前评论草稿保护。
- 处理记录分页顺序、同一时间记录的翻页和访问范围。
- 规则页、训练入口、记录接口与加载文件的一致性。

旧页面检查中仍有已复现的问题，不将失败项计为通过。以上记录也不代表所有设备、平台、工具和真实收发均已验收。
